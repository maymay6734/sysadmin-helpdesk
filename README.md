# SysAdmin Helpdesk — Мобильное приложение для сбора и обработки заявок сисадмина

Полнофункциональный комплекс:
1. **Бэкенд** на **Python (FastAPI + SQLite)** — принимает заявки, фотографии, хранит статусы и комментарии сисадмина.
2. **Мобильное приложение** на **React Native (Expo)** — работает на **Android**, **iOS** (через Expo Go или готовый APK), а также в веб-браузере.

---

## 🚀 Возможности системы

### 1. Режим сотрудника (пользователя)
- **Создание заявки:**
  - 📍 **Локация**: указание точного места (кабинет, этаж, здание) с быстрыми подсказками.
  - 📝 **Описание проблемы**: подробный текст неисправности.
  - 📂 **Категории**: ПК / Ноутбук, Принтер / МФУ, Сеть / Wi-Fi, ПО / 1С / Почта, Доступ / Пароль, Другое.
  - ⚡ **Приоритет**: Обычный, Высокий, Срочно 🚨.
  - 📸 **Фотофиксация**: возможность сделать фото прямо с камеры телефона или выбрать из галереи (поддерживается несколько фото).
  - 👤 **Контакты**: имя заявителя и телефон / Telegram.
- **Мои заявки:**
  - Просмотр списка поданных заявок с цветовыми бейджами статусов:
    - 🟡 **Новая**
    - 🔵 **В работе**
    - 🟢 **Выполнено**
    - 🔴 **Отклонено**
  - Просмотр ответа / отчета системного администратора.

### 2. Панель Системного Администратора (защищена PIN-кодом)
- **Вход по PIN-коду**: по умолчанию `1234` (кнопка «Сисадмин» в правом верхнем углу).
- **Счетчики статистики**: Всего, Новые, В работе, Решено.
- **Поиск и фильтры**: быстрый поиск по тексту/локации, фильтрация по статусам.
- **Управление заявками**:
  - Кнопка **«Взять в работу»** (переводит статус в *В работе*).
  - Кнопка **«Выполнено»** (переводит в *Выполнено*).
  - Кнопка **«Отклонить»**.
  - Кнопка **«Ответить / Изменить ответ»**: добавление комментария для сотрудников (например, *«Заменил сетевой провод, принтер печатает»*).
  - Просмотр прикрепленных фото в полном размере по клику.

## 🏃 Быстрый запуск

### Шаг 1: Запуск бэкенда (Python FastAPI)
Дважды кликните по файлу **`start-backend.bat`**  
или выполните в терминале:
```powershell
cd C:\Users\User\.gemini\antigravity\scratch\sysadmin-helpdesk\backend
.\venv\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
Бэкенд запустится на всех сетевых интерфейсах (`0.0.0.0:8000`), поэтому смартфоны в одной Wi-Fi сети смогут обращаться к нему по вашему локальному IP (`http://192.168.1.161:8000`).

---

### Шаг 2: Запуск мобильного приложения (Expo / React Native)
Дважды кликните по файлу **`start-mobile.bat`**  
или выполните в терминале:
```powershell
cd C:\Users\User\.gemini\antigravity\scratch\sysadmin-helpdesk\mobile-app
npx expo start
```

После запуска в терминале появится большой **QR-код**:
1. **На смартфоне**: установите бесплатное приложение **Expo Go** (есть в Google Play и App Store).
2. На **Android**: откройте Expo Go и нажмите *«Scan QR code»*.
3. На **iOS (iPhone)**: откройте обычную стандартную Камеру и наведите на QR-код.
4. Приложение сразу откроется на вашем телефоне!
5. **В браузере на ПК**: нажмите клавишу `w` в консоли Expo, чтобы открыть веб-версию.

## 🔒 Настройки и PIN-код админа
- **Стандартный PIN-код сисадмина**: `1234` (можно изменить в переменной окружения `ADMIN_PIN` или в `backend/main.py`).
- **Смена IP-адреса сервера**: в правом верхнем углу приложения есть иконка шестерёнки ⚙️. Там можно проверить статус связи с сервером и при необходимости сменить IP-адрес на актуальный.
