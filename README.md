# 🖥️ IT Service Desk — Веб-приложение для системного администратора

Готовое к работе веб-приложение для приема и обработки заявок сотрудников компании с поддержкой прикрепления фото, вставки скриншотов из буфера обмена (Ctrl+V), съемки с камеры смартфона, панелью сисадмина и оповещениями в Telegram.

Работает 24/7, доступно с компьютеров и любых мобильных телефонов, разворачивается на собственном домене **без VPN**.

---

## 🚀 Возможности системы

### 👤 Для сотрудников (клиентская часть):
- **Быстрая подача заявки:**
  - ФИО сотрудника и локация (кабинет, этаж, рабочее место) — **автоматически сохраняются в браузере**, повторно вводить не нужно.
  - Категории: *Компьютер / Ноутбук, Принтер / МФУ, Интернет / Сеть, 1С / Программы, Доступы / Пароли, Прочее*.
  - Приоритет: *Обычная* или *Срочная 🔥*.
  - Подробное описание неисправности.
- **Работа с фото и скриншотами:**
  - 📸 **Кнопка «Сделать фото»** — прямо открывает камеру на смартфонах.
  - 📋 **Вставка из буфера обмена (Ctrl+V)** — сделали скриншот ошибки Windows через PrintScreen или «Ножницы» и нажали `Ctrl+V` на странице.
  - 🖱️ **Drag & Drop** — перетаскивание картинок мышью.
  - Превью прикрепленных миниатюр с возможностью удаления.
- **Вкладка «Мои заявки»:**
  - Просмотр истории своих обращений и их текущих статусов (*Новая ➔ В работе ➔ Решена*).
  - Отображение ответа и заметок системного администратора.

### 🛡️ Для системного администратора:
- **Защита входа:** авторизация по PIN-коду (по умолчанию: `1234`, настраивается в панели).
- **Живая статистика:** всего заявок, новые (с пульсирующим бейджем), в работе, решенные.
- **Звуковое оповещение 🔔:** звуковой сигнал при появлении новой заявки.
- **Фильтрация и быстрый поиск:** моментальный поиск по номеру, тексту, кабинету или имени.
- **Управление статусом в 1 клик:** «Взять в работу», «Решено», «Отклонить».
- **Заметки сисадмина:** поле для ответа заявителю (например, *«Картридж заменен»*, *«Перезагрузил свитч»*).
- **Полноэкранный просмотр фото:** зум фото в оригинальном качестве в модальном окне.
- **Оповещения в Telegram ✈️:** моментальное уведомление сисадмину на телефон с текстом заявки, контактами и прикрепленной фотографией!

## 💻 Быстрый запуск на Windows (в офисе / локально)

1. Дважды кликните по файлу `start-windows.bat`.
2. Скрипт сам запустит сервер и покажет ссылки:
   - На этом ПК: `http://localhost:8000`
   - Для сотрудников с телефонов и соседних ПК: `http://192.168.x.x:8000`
3. Откройте в браузере и пользуйтесь!

## 🌐 Как выложить в интернет на домен 24/7 БЕЗ VPN

Многие зарубежные бесплатные платформы (Vercel `*.vercel.app`, Cloudflare Workers `*.workers.dev`, Hugging Face `*.hf.space`) блокируются или работают нестабильно на территории РФ. 

Ниже представлены **4 надежных способа**, которые работают стабильно 24/7/365 без VPN:

---

### Вариант 1 (Рекомендуемый): Недорогой VPS сервер + собственный домен

Это стандарт для корпоративных сервисов. Стоимость VPS составляет всего 150–250 рублей в месяц (хостинги: **Timeweb Cloud**, **Beget**, **Selectel**, **FirstVDS**, **Aeza**), а домен в зоне `.ru` стоит ~150-200 руб/год.

#### Инструкция по настройке за 5 минут:
1. Зарегистрируйтесь на любом хостинге (например, [Timeweb Cloud](https://timeweb.cloud/) или [Beget](https://beget.com/)) и создайте самый дешевый сервер с **Ubuntu 22.04 / 24.04**.
2. В панели управления доменом добавьте **A-запись**, указывающую на IP-адрес вашего VPS:
   ```
   Имя: support (или @ для основного домена)
   Тип: A
   Значение: IP_ВАШЕГО_СЕРВЕРА
   ```
3. Подключитесь к VPS по SSH и выполните команды:
   ```bash
   git clone https://github.com/maymay6734/sysadmin-helpdesk.git
   cd sysadmin-helpdesk
   chmod +x deploy-vps.sh
   ./deploy-vps.sh
   ```
4. Скрипт спросит ваш домен (например, `support.company.ru`) и PIN-код, сам установит Docker, соберет проект и запустит веб-сервер **Caddy**, который **автоматически выпустит бесплатный SSL-сертификат (HTTPS)**!
5. Всё! Сервис работает 24/7 по адресу `https://support.company.ru` без всяких VPN из любой точки мира.

---

### Вариант 2: Российское облако Amvera Cloud (Без VPS)

Если вы не хотите настраивать Linux-сервер:
1. Зарегистрируйтесь на **[amvera.ru](https://amvera.ru/)** (российское облако, дата-центр в РФ, дается бесплатный баланс при регистрации).
2. Создайте проект с типом «Приложение».
3. Привяжите репозиторий GitHub `maymay6734/sysadmin-helpdesk`.
4. В настройках укажите постоянный диск (Persistent Volume) для папки `/app/uploads` и файла `/app/helpdesk.db`.
5. Amvera автоматически соберет проект по файлу `Dockerfile` и выдаст постоянную ссылку `https://your-name.amvera.io` или позволит привязать свой домен. Доступно в РФ без VPN.

---

### Вариант 3: Офисный ПК + Cloudflare Zero Trust Tunnel (Бесплатно, без белого IP)

Если у вас в офисе есть сервер или ПК, который включен 24/7, и вы не хотите платить за VPS:
1. Зарегистрируйтесь на [Cloudflare](https://dash.cloudflare.com/) и добавьте свой домен.
2. Перейдите в раздел **Zero Trust ➔ Networks ➔ Tunnels**.
3. Создайте новый туннель и скачайте коннектор `cloudflared` для Windows или Linux.
4. В настройках маршрута (Public Hostname) укажите:
   - Service: `HTTP`
   - URL: `localhost:8000`
   - Domain: `support.yourdomain.ru`
5. Ваш офисный сервер станет доступен всему миру по защищенному адресу `https://support.yourdomain.ru` даже без статического белого IP! При привязке своего домена Cloudflare не блокируется.

## ✈️ Настройка оповещений в Telegram

Системному администратору не нужно сидеть перед открытой вкладкой браузера — новые заявки с фотографиями сразу приходят в Telegram.

1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`, укажите имя и получите **Bot Token** (вид: `1234567890:ABCdef...`).
3. Откройте диалог с созданным ботом и нажмите кнопку **/start**.
4. Узнайте свой Telegram Chat ID (напишите боту **[@userinfobot](https://t.me/userinfobot)**, он пришлет ваш `Id`). Если хотите получать заявки в группу — добавьте бота в группу и укажите ID группы.
5. В приложении IT Service Desk войдите под сисадмином (PIN: `1234`), нажмите иконку ⚙️ **«Настройки»**, введите токен и chat ID, включите тумблер и нажмите **«Проверить отправку»**.
6. Готово! Теперь при любой заявке в Telegram прилетает сообщение:
   ```
   🚨 Новая заявка #15
   📍 Локация: Кабинет 304, стол у окна
   👤 Заявитель: Анна Смирнова (+7 999 123-45-67)
   🏷 Категория: Принтер / МФУ
   🔥 Приоритет: Срочный
   📝 Описание проблемы: Зажевало лист в печке, горит красная лампа
   [Прикрепленное фото ошибки]
   ```
